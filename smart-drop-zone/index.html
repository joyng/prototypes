      How it decides
      
    
      Conversion is deterministic and runs in the browser. The agent only advises, and only where the service’s data classification allows it.
      
  
      
  
      
    
      
      
      
        Behaviour by file size
        
      File sizeBehaviour
      
        
          
      Within the agency limitConverted in the browser if the format differs
      
          
      Above the limit, below the ceilingReduced after approval, with a time estimate for large files
      
          
      Above the ceilingRefused, with guidance on how to make it smaller
      
              
      
      
    
      
    
      
      
      
        Behaviour by type of change
        
      Type of changeUser interaction
      
        
          
      Format only (HEIC to PDF)Shown on the file; no approval
      
          
      Content changing (remove pages, compress, lower video quality)Preview and explicit approval; the user can keep the original
      
          
      Agent check (wrong document)Advice only; never blocks or changes the file
